# 열강의 시대 1900 (Age of Great Powers 1900)

1900년 1월, 52개 나라 중 하나를 골라 20세기를 시작한다.
공장을 세우고, 기술을 좇고, 동맹을 맺고, 전쟁을 치러 **열강의 반열에 올리는 것**이 목표다.

브라우저만 있으면 된다. **설치도, 서버도, 인터넷도 필요 없다.**

---

## 실행 방법

- Windows: `START_GAME.bat` 더블클릭
- 그 외: `index.html`을 브라우저로 열기

## 업데이트 — 한 번에

게임이 갱신되면 **터미널에 한 줄**이면 된다. 최신 내용을 받아 적용하고 게임까지 열어준다.

```bat
:: Windows — 더블클릭하거나 터미널에서
great-power\UPDATE.bat
```
```bash
# macOS / Linux
./great-power/update.sh
```

로컬에서 파일을 고쳐 충돌이 나면 스크립트가 알려주고, 내 수정을 버리고 맞추는 명령
(`git reset --hard origin/claude/great-power-1900`)까지 같이 안내한다.
현재 버전은 시작 화면 위쪽과 `VERSION` 파일에서 볼 수 있다.

## 무엇이 들어 있나

### 실제 세계지도
Natural Earth 1:50m 지도를 가공해 만든 **186개 프로빈스**. 러시아·미국·중국·인도·캐나다·브라질·호주는
역사적 지역 단위로 쪼개져 있어(만주·신장·티베트·극동·화북·화남·북인도…) 전선이 생긴다.
프로빈스마다 1900년 기준 소유국·인구·개발도·지형·자원이 들어 있고, 육상 인접과 해상 항로가
지도 데이터에서 자동 계산된다. 해안선 비율로 **내륙국은 해군을 가질 수 없다.**

### 나라와 정치
- 52개국. 1900년의 실제 정세 — 인도·이집트·수단은 영국령, 인도차이나는 프랑스령,
  콩고는 벨기에 국왕의 사유지, 조선은 대한제국, 청은 아직 제국.
- **9개 정부형태**: 절대군주제 · 입헌군주제 · 의회공화정 · 대통령제 공화국 · 군사정권 · 신정 ·
  식민 자치령 · (해금) 사회주의 공화국 · (해금) 국가주의 독재.
  체제마다 세수·연구·안정·정치력·군사력 보정이 다르다.
- **행정역량(ADMIN)**: 청과 오스만이 인구는 많은데 가난한 이유. 재정 침투율이 낮다.
- 안정도·정통성·불만·반란·핵심주 동화. 점령지는 오래 쥐고 있어야 내 땅이 된다.

### 기술 트리 — 산업 / 정치 / 군사
분야마다 14개, 총 42개. 연도 제한이 걸려 있어 1900년에 전차를 연구할 수 없다.

| 산업 | 정치 | 군사 |
|---|---|---|
| 증기기관 → 철도망 → 제강법 → 전력화 → 컨베이어 → 중공업 → 원자력 | 관료제 → 의무교육 → 중앙은행 → 참정권 → 총력전 → 계획경제 → 총동원법 | 무연화약 → 기관총 → 예비군 동원 → 드레드노트 → 참호전 → 전차 → 전격전 |

연구력은 **인구 × 개발도**에서 나온다. 공장을 세우면 세수·연구·인력이 함께 오른다.
세 분야에 배분 비율을 조절할 수 있으니, 약소국은 한 분야에 몰아넣는 편이 낫다.

### 부대 지휘 — 드래그로 고르고, 우클릭으로 보낸다

| 조작 | 결과 |
|---|---|
| **좌클릭 드래그** | 상자 안의 내 부대·함대를 모두 선택 (Shift = 추가) |
| **좌클릭** | 프로빈스 선택 / 마커를 누르면 그 부대만 선택 |
| **우클릭** | 선택한 부대에게 그곳으로 가라고 명령 |
| **우클릭 드래그** | 지도 이동 (가운데 버튼 드래그도 됨) |
| **Ctrl+A / Esc** | 전군 선택 / 선택 해제 |

우클릭한 곳이 **붙어 있으면** 그 달에 바로 이동하거나 공격하고, **멀면 진군 명령**이 걸려
매달 한 칸씩 스스로 전진한다. 길에 적이 있으면 알아서 교전하고, 도착하면 명령이 풀린다.
지도에 진군 경로가 화살표 점선으로 그려진다.
통행권이 없는 남의 땅은 지나갈 수 없다 — 전쟁 중이거나 동맹국 영토여야 한다.

함대도 똑같다. 여러 해역을 거쳐야 하는 먼 목적지도 항로가 자동으로 잡힌다.

### 장군
부대에 장군을 붙이면 그 부대가 달라진다. 지휘 능력(1~10)과 특성이 전투에 직접 반영된다.

- 특성 9종: 돌격전문 · 방어전문 · 보급 귀재 · 신중함 · 기병 출신 · 공성 전문 ·
  냉혹함 · 병사의 아버지 · 해군 제독
- 이기면 경험이 쌓여 **지휘 능력이 오른다.** 나이를 먹고 예편한다.
- 장군 정원은 **육군 규모에 비례**한다. 군이 작으면 둘밖에 못 둔다.
- 장군은 자기가 맡은 **주력을 따라 이동한다.**

### 해군 — 23개 해역
함선은 창고 속 숫자가 아니라 **바다 위에 떠 있다.**

- 세계가 북해·발트해·동지중해·흑해·카리브해·동해·남중국해 등 **23개 해역**으로 나뉜다.
- 함대는 한 달에 한 번, 맞닿은 해역으로 움직인다. 지도에서 함대를 누르고 옆 해역을 누르면 된다.
- **해전**: 적대하는 함대가 같은 해역에 있으면 교전하고, 진 쪽은 자국 해안이 있는 해역으로 물러난다.
- **봉쇄**: 적 해안에 접한 해역을 우세하게 장악하면 그 지역의 세수가 **55% 줄어든다.**
- **상륙**: 해역별로 함대를 정확히 배치해 둘 필요는 없다. 출발지와 목적지가 **둘 다 바다에 면해 있고**,
  자국 해군 총량이 거리와 상대 해군력에 따른 요구치를 넘으면 그대로 상륙할 수 있다.
  가까운 약소국은 함선 몇 척으로 충분하고, 먼 바다의 해군 강국은 훨씬 많은 함대가 필요하다 —
  거리와 적 해군에 따라 요구 척수가 매끄럽게 늘어난다. 어떤 나라든 앞바다를 지킬 **최소 6척**은
  갖출 수 있어, 약소국도 인근의 무방비 식민지 정도는 충분히 노려볼 만하다.
- **파나마 운하**는 1914년에 열려 카리브해와 남미 태평양이 이어진다.
- 내륙국은 함대를 가질 수 없고, 조선 능력(최소 6척 이상)은 나라 전체의 공업력이 결정한다.

### 내각 — 7개 부처
총리 · 재무 · 국방 · 외무 · 내무 · 상공 · 식민.

각 인물은 **행정 / 카리스마 / 군사 / 경제 / 외교** 5개 능력치(1~10)와 특성을 갖는다.
부처마다 핵심 능력이 달라서, 같은 사람이라도 어디에 앉히느냐가 중요하다.

| 부처 | 핵심 능력 | 효과 |
|---|---|---|
| 총리 | 행정·카리스마 | 안정도, 정치력 |
| 재무대신 | 경제 | 세수, 건설비 |
| 국방대신 | 군사 | 공격력, 방어력 |
| 외무대신 | 외교 | 외교 행동 효과 |
| 내무대신 | 행정 | 지방 불만, 안정도 |
| 상공대신 | 경제·행정 | 산업, 개발 성장 |
| 식민대신 | 행정·카리스마 | 식민 수입 |

특성은 철혈 · 은행가 출신 · 부패 · 개혁가 · 수구파 · 군벌 · 학자 · 노회한 외교가 ·
선동가 · 무능 · 국민적 인기 · 식민지 경영자 · 공학자 · 정보통 · 대귀족 · 대중정치가 등 16종.

- **임명** 정치력 20, **해임** 정치력 25.
- 국민적 인기가 있는 인물을 내치면 여론이 들끓고, 군벌을 내치면 군부가 동요한다.
- 장관은 나이를 먹고, 죽거나 사임한다. **공석은 안정도를 깎는다**(탭에 빨간 숫자로 표시).
- 나라마다 이름이 문화권에 맞게 생성된다 — 일본은 이토·가쓰라, 독일은 폰 뷜로·티르피츠,
  영국은 체임벌린·그레이, 조선은 김·이·박.

### 전쟁
- **개전 명분**이 필요하다: 국경 분쟁 / 정복 / 식민지 요구 / 속국화 / 민족 해방 / 굴욕 요구 / 명분 없음.
  명분이 거칠수록 정치력이 많이 들고, 전 세계의 관계가 나빠지며, 다음 전쟁 때 연합의 표적이 된다.
- 전투는 **병력 × 기술 × 사기 × 보급** 대 **병력 × 지형 × 요새 × 본토 방어**로 판정된다.
  산지는 방어 1.4배, 정글은 보급 0.65배. 상륙작전은 공격력이 28% 깎이고 해군이 있어야 한다.
- 수비병이 없는 지역은 **포위**로 서서히 함락된다.
- 전쟁 점수에 따라 요구할 수 있는 것이 달라진다:
  백지 강화 → 배상금(15) → 영토 1곳(25) → 2곳(45) → 4곳(65) → 속국화(80) → 병합(95).

#### 점령과 소유는 다르다

적 영토를 점령해도 **소유권은 그대로 적국에 남는다.** 지도에서 빗금으로 표시되며,
실제로 내 땅이 되려면 **강화 조약**을 맺어야 한다.

- 지도 오른쪽 위 **전쟁 패널**에 전쟁 점수와 지금 요구 가능한 조건이 뜨고,
  거기서 바로 강화 협상에 들어갈 수 있다. 점령한 지역을 클릭해도 같은 버튼이 나온다.
- 강화 창에는 **잠긴 조건도 이유와 함께** 보인다 ("전쟁 점수 80 필요 (현재 64)" 등).
- **상대의 전 국토를 점령했다면** 점수 문턱이 내려간다 — 속국화 55, 병합 60.
  시암처럼 작은 나라는 전 국토를 점령해도 점수가 95까지 오르지 않아
  예전에는 병합이 영원히 불가능했다.
- 병합에는 추가 조건이 있다: 상대 영토 4곳 이하, 그리고 개전 후 일정 기간
  (영토 2곳 이하면 6개월, 그 이상이면 12개월).
- 병합하면 그 지역은 즉시 **내 나라 색으로 바뀌고** 영토로 편입된다.
  다만 핵심주가 아니라 불만이 높으니 총독부를 세워 가라앉혀야 한다.
- 명령창으로도 된다: `시암 병합`, `시암 속국화`, `시암 할양`, `강화`
- 전사자는 한동안 동원 인력에서 빠진다. 전쟁 피로가 쌓이면 안정도가 무너진다.
- 강화 후 5년간 정전.

관계 개선 · 외교적 경고 · 동맹 · 불가침 · 독립 보장 · 재정 지원 · 조공 요구 · 동맹 파기.

## 명령 콘솔 — 타이핑하는 대로

화면 아래 입력창에 **한국어로 적으면 그대로 실행된다.** 외부 서버를 쓰지 않으므로 **비용이 0원**이다.

```
독일에 선전포고              청에 정복 전쟁            모로코에 식민지 요구
만주 공격                   알자스 침공 10개 사단      화북에서 만주로 이동
프랑스와 동맹                영국 관계 개선            일본 규탄
러시아와 강화                공장 건설                 화북에 요새 건설
5개 사단 모병                군함 3척 건조             드레드노트 연구
산업 연구                   입헌군주제로 변혁          세율 110
국채 200                    부채 상환                 다음 달
저장                        불러오기                  도움말
```

지역 이름은 지도에 적힌 그대로 쓰면 되고, 지역을 적지 않으면 **지도에서 선택한 지역**이 대상이 된다.
`도움말`을 입력하면 전체 목록이 나온다.

> **왜 진짜 AI가 아닌가**
> 자유로운 문장을 매번 해석하려면 LLM API를 호출해야 하고, 그건 호출할 때마다 실제로 돈이 나간다.
> 그래서 이 게임은 **규칙 기반 한국어 파서**로 같은 일을 한다. 표현을 조금 바꿔도(공격/침공/진격,
> 모병/징집/동원) 알아듣고, 요금은 영원히 0원이다.

## 치트 모드 — `F4`

아무 때나 **F4**를 누르면 치트 패널이 열린다(다시 누르면 닫힘). 눌러서 쓰는 것 외에
명령창에도 `돈 5000`, `기술 전부`, `병력 30`, `즉시 승리`, `무적` 처럼 칠 수 있다.

| 갈래 | 할 수 있는 것 |
|---|---|
| 재정 | 국고 +£1,000 / +£10,000 · 부채 탕감 · 정치력 +500 |
| 내정 | 안정도 100 · 전 국토 불만 0 · 위신 +100 · 전쟁 피로 0 · 전 국토 개발 최대 |
| 기술 | 연구 중인 것 즉시 완료 · 연대 안에서 전부 해금 · 연대 무시하고 전부 해금 |
| 군사 | 사단 10/20개 즉시 배치 · 함선 +20 · 전 국토 요새 5급 · 인력 완전 회복 |
| 영토 | 선택 지역 병합 · 국경에 닿은 지역 전부 병합 |
| 전쟁 | 진행 중인 전쟁 즉시 승리(점수 100 + 전 영토 점령) · 전부 백지 강화 |
| 외교 | 모든 나라와 관계 +100 · 열강 전부와 동맹 · 침략 평판 초기화 |
| 특수 | 무적 모드(전투·산업·연구·세수 3배) · 1년 건너뛰기 · 공사 즉시 완료 |

한 번이라도 쓰면 상단에 **치트** 표시가 붙고 기록에도 남는다.

## 승리

설정한 종료 연도(1930 / 1950 / 1970)까지

- **1위** — 세계의 중심
- **2~3위** — 열강의 반열
- **4~8위** — 열강의 말석
- 그 아래 — 변방의 나라

국력 = 공업 42% + 군사 30% + 위신 16% + 식민지 7% + 기술 5%

### 약소국 보정

시작 서열이 낮은 나라를 고르면 **플레이어에게만** 완만한 보정이 붙는다 —
연구·세수·개발 속도가 오르고, 본토 방어에 이점이 생기며, 열강이 덜 달려든다.
서열이 낮을수록 강해지고 **열강(1~8위)에게는 아무것도 주지 않는다.**
대한제국·세르비아처럼 맨 밑에서 시작해도 길이 보이도록 만든 장치다.

작게 잘 사는 것만으로는 1위가 되지 않는다. 결국 **영토와 인구**가 필요하다.

```
│   ├── tick.js      월간 진행, 건설·모병·행동
│   ├── ai.js        AI 의사결정
│   ├── events.js    역사·랜덤 사건
│   ├── ui.js        지도 렌더링·패널·모달
│   ├── cheat.js     치트 모드 (F4)
│   ├── cmd.js       한국어 명령 파서
│   └── main.js      시작 화면·턴 진행·저장
├── tools/gen-map.js 지도 생성기 (Node, 재생성용)
├── UPDATE.bat / update.sh  한 줄 자동 업데이트
└── VERSION
```

### 지도를 다시 만들려면

```bash
npm pack world-atlas@2          # countries-50m.json 추출
node tools/gen-map.js js/mapdata.js
```

투영은 Miller 원통도법, 단순화는 TopoJSON **아크 단위**라 국경에 틈이 생기지 않는다.
날짜변경선을 가로지르는 폴리곤은 분할하고, 대국 분할에는 Weiler–Atherton 사각형 클리핑을 쓴다.
