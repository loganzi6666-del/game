# 東亞 群雄割據 — 동아시아 군웅할거

삼국지 7·8 계열의 감각으로 만든 **동아시아판 땅따먹기 전략 시뮬레이션**.
한반도 · 일본 · 중국 · 베트남 · 대만의 54개 주군(州郡)을 32개 세력이 다툰다.

## 실행

```
sangokushi/index.html 을 브라우저로 열면 끝 (설치·서버 불필요)
```
저장은 브라우저 localStorage에 보관된다. 권장 해상도 1280×760 이상.

## 세 가지 플레이 유형

인물 선택 화면에서 **누구를 고르느냐가 곧 플레이 유형**이다.

| 고른 인물 | 유형 | 내용 |
|---|---|---|
| 군주(君) | **군주 플레이** | 세력 전체 지휘. 내정·군사·인사·외교·기술·출병 전권 |
| 일반 장수 | **장수 플레이** | 한 사람으로 시작. 주군의 임무를 수행해 공적을 쌓고 무관→교위→장군→태수→도독→대장군→승상으로 승진. 수련으로 능력치를 올리고, 진언·친교·도적토벌로 입지를 다진다. 불만이 쌓이면 **하야**하거나 **거병**해 독립할 수 있다 |
| 재야(在野) | **방랑 플레이** | 주인 없는 몸. 천하를 유력하며 명성과 동료를 모아 **사관(출사)** 하거나, 명성 110·동료 2인·민심 낮은 성에서 **거병**해 스스로 군주가 된다 |

장수 플레이 중 주군이 죽고 당신이 계승하면 그대로 군주 플레이로 전환된다.
반대로 세력이 멸망하면 재야로 떨어진다. 포로가 되면 항복(새 주군)·석방(재야)·처형(게임오버)이 갈린다.

## 지도

실제 경위도를 투영해 그린 동아시아 전도(x=(경도−95)·30, y=(50−위도)·26).
해안선·큰 하천(황하·장강·한강·낙동강·대동강·메콩·홍하·주강)·해역명이 들어가고,
도시는 가도(육로)·산길·수로·항로로 이어진다. 항로 진격에는 전선이 필요하다.

* **한반도 12** 요동 평양 개성 한성 강릉 청주 상주 전주 나주 진주 경주 제주

* **중국 18** 북평 업 태원 낙양 장안 무위 임치 서주 수춘 건업 회계 양양 형주 장사 성도 한중 남중 번우
* **베트남 5** 대라 청화 순화 참파 사이공
* **대만 3** 대북 대남 화련

지형은 평야·하천·산악·삼림·해안·도서·밀림·고원·분지·설원 10종이며
방어·농업·행군·병종별 보정이 모두 다르다.

## 시스템

### 내정
농업·상업·치수·성벽·치안·민심·인구. 개간/상업/치수/축성/순찰/구휼.
태수의 정치력이 수입과 수확을 좌우하고, 민심이 낮으면 민란이 터져 성이 이탈한다.

### 군사
징병·훈련·무기생산·방어구·군마구입·조선. 병종 7종(보병·궁병·기병·수군·공성·철포·상병).
철포는 조총 기술, 상병은 상병조련 기술이 있어야 편성할 수 있다.

### 인사 / 계략
등용·인재탐색·포상·이동, 첩보·이간·유언비어·방화.
재야 인재는 **인재탐색으로 발굴**해야 등용 목록에 나타난다.

### 외교
관계도(−100~100), 예물·불가침·동맹·정전·선전포고·금 요구·공동출병·신속 요구.
다른 문화권과는 교섭 페널티가 있어 **통역관** 기술이 유용하다.
동맹국에는 조공체제로 금이 들어오고, 신속국은 세를 바친다.

### 기술 테크트리 (35)
내정·군사·외교·문화 네 갈래. 상업·인구·지력 높은 장수에서 매달 연구점이 쌓인다.
나라마다 잘 맞는 기술의 연구비가 싸다.

* 내정 — 우경 → 수차·둔전제 → 대운하·상평창 → 관개대공사 / 화폐주조 → 시장개혁·인구조사
* 군사 — 단련철제 → 강노·등자·진법·조선술 → 개마중기·공성기·화약·상비군·상병조련 → 조총·철갑선
* 외교 — 역참 → 첩보망·조공체제·통역관 → 혼인동맹·이간지계 → 패자책봉
* 문화 — 율령 → 과거제·태학·사관제도 → 종교진흥·무학당 → 천하일통

지역 특화: 한반도 강노·철갑선·율령 / 일본 조총·화약 / 중국 대운하·과거제·공성기 /
베트남 상병조련·통역관 / 대만 조선술·철갑선.

### 전투 — 숫자만으로는 이기지 못한다

부대 실전력 =
`병력 × 훈련도(0.45~1.70) × 사기(0.70~1.20) × 병종계수 × 병과적성(0.82~1.30) ×
장수능력(통솔0.6+무력0.4) × 무기등급(0.93~1.25) × 특기 × 기술 × 지형 × 병종상성(0.80~1.32) × 전술`

검증된 결과(동일 장수·동일 전술 기준):

| 상황 | 결과 |
|---|---|
| 동일 조건 1만 vs 2만 | 패배 (수는 여전히 중요하다) |
| 훈련100·무기4 **1.2만** vs 훈련30·무기1 **2만** | **승리 98%** |
| 명장(김유신)+기병 상성 **4천** vs 오합지졸 **2만** | **승리 100%** |
| 기병으로 산악 공격 | 전력 0.60배 — 궁병·보병을 쓸 것 |
| 성벽 200 수비 | 방어 태세 최대 약 2.5배 — 공성 병종·화약 필요 |

* 병종 상성 — 기병▶보병, 보병▶궁병, 궁병▶기병
* 전술 10종 — 돌격·견수·제사·우회·매복·화계·수공·교란·일기토·철퇴.
  계략은 양측 지력 대결이고, 간파당하면 아군 사기가 떨어진다.
* 매 합마다 성벽이 깎이고 사기가 무너지며, 사기가 다하면 궤멸·퇴각한다.
* 일기토는 무력·특기로 갈리며 전사·부상이 난다. 적장을 사로잡으면 등용·석방·처형을 고른다.
