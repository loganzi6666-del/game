LIFE : RISE V0.8 — COMMAND CENTER UI

- 캐릭터/도시 이동 UI 제거 (기존 DOM은 호환성을 위해 내부적으로만 유지)
- 세련된 전략/경영형 Command Center 대시보드로 전면 개편
- 한 화면에서 순자산, 현금흐름, POWER, 직업, 국회, 대통령, 시장 확인
- 주간 포커스 시스템: 커리어 / 부 / 권력 / 생활을 1클릭으로 일주일 진행
- 숫자키 1~4로 주간 포커스 즉시 실행
- 한 달 진행 버튼: 반복 행동을 줄이고 28일 진행 후 핵심 이벤트 노출
- 현재 가장 중요한 위기/사건을 STORY 카드로 자동 추천
- 투자, 사업, 정치, 국회, 외교, 정보국을 좌측 메뉴에서 즉시 접근
- 권력순위 미니보드 상시 표시
- 시장 가격/등락 미니 티커 상시 표시
- 기존 V0.7의 실명 국회, 선거, 당권, 국정원, 사업, 투자, 탄핵, 군사권력, 국제정치 기능 유지
- 기존 모달 UI도 V0.8 디자인 언어로 통일
