LIFE : RISE V0.9.2

- 능력개발센터를 팝업에서 메인 화면으로 변경
- 좌측 메뉴의 능력개발 클릭 시 화면 전환
- 능력 훈련 버튼을 메인 화면에서 직접 실행
- 좌측 메뉴에 '일하기' 추가
- 무직 상태에서는 단기 아르바이트 가능
- 직업 보유 시 정규근무 / 추가근무 / 집중근무 선택
- 근무 시 실제 실수령 급여, 경력점수, 능력치, 영향력 증가
- 월급 자동 지급 제거: 직접 근무해야 급여 수령
- 사업가는 개인 급여 대신 회사 현금/제품력 성장
- 지하세계는 수익과 함께 수사위험 증가
- 이번 달 근무횟수 / 누적 실수령 / 마지막 근무 표시
- 커리어 화면에서도 바로 '일하기' 진입 가능
- W 키로 일하기 화면 바로 열기
