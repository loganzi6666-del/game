LIFE : RISE V0.9.9

LIFE : RISE V0.9 — COMMAND CENTER

실행
1. 압축을 풉니다.
2. START_GAME.bat 실행 또는 index.html 더블클릭
3. Chrome / Edge 권장

게임 방향
LIFE : RISE는 캐릭터를 직접 조종하는 게임이 아니라, 인생·직업·돈·사업·정치·군·정보·외교를 한 화면에서 관리하는 전략/경영형 인생 시뮬레이션입니다.
중요한 사건은 COMMAND INBOX로 들어오고, 나머지 세계는 주/월 단위로 자동 진행됩니다.

V0.9 핵심
- NEWSROOM / 속보 / SNS 여론과 트렌딩
- 풋볼매니저형 중요 의사결정 인박스
- 순자산·권력·시장·민심 추세 차트
- 커리어/투자/사업/정치/권력/외교/정보국 전용 화면
- 군 계급 세분화: 대령 → 준장 → 소장 → 중장 → 대장
- 장성 진급 심사: XP + 리더십 + 군 영향력 + 평판 + 인맥 + 지휘신뢰
- 핵심 보직 선택과 장성 전용 사건
- 장성/전문가가 성공하면 대통령실·장관·여야 정당에서 영입 제안
- 제안을 수락하거나 거절하거나 조건을 협상 가능

기존 시스템 유지
- 현실경제 난이도, 주식/ETF/채권/코인, 공매도
- 창업, 직원, 투자유치, IPO, M&A
- 국회/선거/정당/당권/탄핵
- 대통령 국정운영, 외교·국제위기
- 군사 권력변동은 추상적인 게임 수치 기반
- 정보기관 커리어와 가상 인물/가상 조직 대상의 첩보 이벤트

정치 관련 안내
- 시작 시점의 현실 정치·국회 데이터는 현실 정보를 참고합니다.
- 게임 시작일 이후 발생하는 인사, 정당 영입, 표결, 선거, 외교·정국 변화는 가상 시뮬레이션이며 실제 미래 예측이 아닙니다.
