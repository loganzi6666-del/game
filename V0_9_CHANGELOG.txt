LIFE : RISE V0.9 — NEWSROOM / COMMAND INBOX / ELITE CAREER UPDATE

[플레이 루프]
- 캐릭터 이동 없이 COMMAND CENTER 방식 유지
- 주간 포커스 / 다음 주 / +1개월 진행
- NEWSROOM: 경제, 증시, 커리어, 기업, 정치, 외교·안보 상황에 맞춘 헤드라인 생성
- SOCIAL PULSE: 대중 호감도, 팔로워, 화제성, 트렌딩 태그
- COMMAND INBOX: 자동으로 넘기면 안 되는 제안/인사/위기만 모아 결정
- 자산/권력/시장/민심 추세 그래프
- 커리어, 투자, 사업, 정치, 권력관계, 외교, 정보국 전용 대시보드

[군인 커리어 대규모 개편]
- 계급: 훈련병 → 소위 → 중위 → 대위 → 소령 → 중령 → 대령 → 준장 → 소장 → 중장 → 대장
- 참모총장/합참의장은 계급이 아니라 대장급 '보직'으로 분리
- 대령 이후 진급 난이도 상승
- 장성 진급은 경력점수뿐 아니라 리더십, 군 영향력, 평판, 인맥, 지휘신뢰를 종합 판정
- 준장 이상 별 표시 및 장성 전용 커리어 UI
- 핵심보직 선택: 연대장, 여단장, 사단장, 군단장, 합참, 국방부 정책라인, 참모총장/합참의장 후보 등
- 장성 전용 사건: 국방개혁, 국회 인사검증, 핵심보직 경쟁

[정치권 영입 / 장관 임명]
- 준장급 이상: 제1야당 인재영입 제안 가능
- 소장급 이상: 대통령실 국가안보 라인 제안 가능
- 중장급 이상: 국방부 장관 임명 제안 가능
- 대장급 + 높은 평판/권력: 대선후보 영입 또는 킹메이커 제안 가능
- 단순 수락/거절 외에 지역구 출마 협상, 다른 안보보직 역제안 등 선택지 추가
- 군인 외에도 의사/검사/변호사/경찰/기업인/사업가/정보기관/연예·스포츠 커리어에서 높은 경지에 도달하면 관련 장관·정치 영입 제안 가능
- 게임 시작 시점 이후의 영입/인선/선거 결과는 모두 게임 시뮬레이션
